# RefCompare

本目录参考了[learnXinYminutes](https://learnxinyminutes.com/)网站的风格，希望可以快速复习一个编程语言的语法。

目前有以下内容：

- [[C++]]
- [[Python]]
- [[Java]]
- [[JavaScript]]
- [[Go]]
- [[Rust]]
- [[Swift]]
- [[Haskell]]
- [[Lua]]
- [[Matlab]]
- [[R]]
- [[TypeScript]]

每一个语言都按照 Roadmap.sh 上面的路线图，设置章节结构标题。每一个小节只添加示例代码以及 wikilink 指向其他课程里面相关知识点的部分。
