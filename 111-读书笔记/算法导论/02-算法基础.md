## 2.1 插入排序

先定义我们在第一章引入的**排序问题**：

**输入**：$n$个数的一个序列 $A = \{a_1, a_2, ..., a_n\}$。
**输出**：输入序列的一个排列 $A' = \{a'_1, a'_2, ..., a'_n\}$，满足 $a'_1 \le a'_2 \le ... \le a'_n$。

然后让我们看一下**插入排序**。

插入排序就像是排序扑克牌一样。开始的时候左手为空并且桌子上的牌面朝下；然后每次从桌子上拿走一张牌并且按照从左往右（也可以是从右往左）的顺序，依次和左手中的牌比较大小并且插入到正确位置。

通常将算法描述为用一种**伪代码**书写的程序。具体什么是伪代码，如何书写伪代码，我们会在后面提到。

### 伪代码的一些约定

1. 用缩进表示**块结构**。不用`begin`和`end`
2. 用`while`, `for`, `repeat-until`表示**循环结构**。用`if-else`表示**分支结构**。
3. 用符号`//`表示该行后面的部分是注释

- 形如`i=j=e`的多重赋值语句将表达式`e`的值赋给变量`i`和`j`。等价于`j=e`后跟着`i=j`。
- 变量是局部于给定过程的。除非显式说明，否则不用全局变量
- 数组元素通过`数组名[下标]`的形式访问。`A[i]`表示数组`A`的第`i`个元素，`A[i..j]`表示`A`的一个子数组，包含从`i`到`j`的所有元素：`A[i], A[i+1], ..., A[j]`

## 2.2 分析算法

在能够分析一个算法之前，我们必须先要有一个模型，包含所用资源及其代价。对于本书而言，我们主要用的计算模型是：**随机访问机**(random-access machine, RAM)。在 RAM 模型中，指令按照顺序执行，没有并发操作。
