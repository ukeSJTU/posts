## 1. 分治法 (Divide and Conquer)

分治法是一种算法设计范式，它通过将问题分解为更小的子问题，解决这些子问题，然后将结果合并以获得原始问题的解决方案。

### 1.1 Karatsuba 整数乘法

**基本思想**：

- 将两个大整数分解为较小的部分，减少乘法操作的数量
- 对于两个 n 位数的乘法，传统方法需要 O(n²)次操作，Karatsuba 算法降低到 O(n^log₂3)≈O(n^1.585)

**算法步骤**：

1. 将 n 位整数 x 和 y 分别拆分为两部分：x = a·10^(n/2) + b，y = c·10^(n/2) + d
2. 计算三个乘积：ac、bd 和(a+b)(c+d)
3. 最终结果：xy = ac·10^n + [(a+b)(c+d) - ac - bd]·10^(n/2) + bd

**时间复杂度**：T(n) = 3T(n/2) + O(n) = O(n^log₂3)

### 1.2 归并排序 (Merge Sort)

**基本思想**：

- 将数组分成两半，对每一半递归排序，然后合并两个已排序的子数组

**算法步骤**：

1. 将输入数组分为两个大小相等的子数组
2. 递归地对这两个子数组进行排序
3. 合并两个已排序的子数组

**时间复杂度**：O(n log n)

### 1.3 计算逆序对 (Count Inversions)

**问题定义**：

- 在数组中，如果 i < j 但 a[i] > a[j]，则称(i,j)是一个逆序对

**算法思想**：

- 利用归并排序的思想，在归并过程中计算逆序对的数量

**算法步骤**：

1. 将数组分为两半
2. 递归计算左半部分和右半部分的逆序对数量
3. 在合并过程中，计算跨越左右两部分的逆序对数量
4. 总逆序对数量 = 左半部分逆序对 + 右半部分逆序对 + 跨越的逆序对

**时间复杂度**：O(n log n)

### 1.4 选择问题 (Selection)

**问题定义**：

- 在一个包含 n 个元素的集合中找到第 k 小的元素

**算法思想**：

- 使用分治法，通过选择一个"枢轴"元素来划分数组

**算法步骤**：

1. 选择一个枢轴元素 p
2. 将数组划分为三部分：小于 p 的元素 L，等于 p 的元素 M，大于 p 的元素 R
3. 根据 k 的值和 L、M 的大小，决定在哪个部分继续搜索：
   - 如果 k ≤ |L|，在 L 中寻找第 k 小元素
   - 如果|L| < k ≤ |L|+|M|，返回 p
   - 如果 k > |L|+|M|，在 R 中寻找第(k-|L|-|M|)小元素

**时间复杂度**：

- 最坏情况：O(n²)
- 平均情况：O(n)

### 1.5 最近点对问题 (Closest Pair)

**问题定义**：

- 给定平面上 n 个点，找出距离最近的一对点

**算法思想**：

- 使用分治法，将点集按 x 坐标排序并分为两半，递归求解，然后处理跨越中线的点对

**算法步骤**：

1. 将点集按 x 坐标排序
2. 将点集分为左右两部分
3. 递归求解左右两部分的最近点对，得到距离 δ
4. 考虑跨越中线的点对，只需检查中线附近宽度为 2δ 的带状区域内的点
5. 在该带状区域内，按 y 坐标排序，对每个点只需检查其后有限个点

**时间复杂度**：O(n log n)

### 1.6 快速傅里叶变换 (Fast Fourier Transform, FFT)

**问题背景**：

- 多项式乘法：给定两个 n-1 次多项式，计算它们的乘积

**算法思想**：

- 利用多项式插值定理，通过在特定点上的值来表示多项式
- 使用单位复数根作为评估点，利用其特殊性质进行高效计算

**算法步骤**：

1. 插值步骤(FFT)：选择 2n-1 个不同的点，计算两个多项式在这些点上的值
2. 乘法步骤：对应点上的值相乘
3. 恢复步骤(逆 FFT)：从乘积多项式在各点上的值恢复系数

**时间复杂度**：O(n log n)

## 2. 图论 (Graphs)

图论算法处理由顶点和边组成的图结构，解决路径、连通性、流等问题。

### 2.1 深度优先搜索 (Depth-First Search, DFS)

**基本思想**：

- 从一个起始顶点开始，尽可能深地探索一条路径，然后回溯

**算法步骤**：

1. 从起始顶点开始，标记为已访问
2. 对于当前顶点的每个未访问的邻接顶点，递归地进行 DFS
3. 如果所有邻接顶点都已访问，则回溯

**应用**：

- 检测环
- 拓扑排序
- 寻找连通分量
- 寻找强连通分量

**时间复杂度**：O(|V| + |E|)，其中|V|是顶点数，|E|是边数

### 2.2 广度优先搜索 (Breadth-First Search, BFS)

**基本思想**：

- 从起始顶点开始，先访问所有距离为 1 的顶点，然后是距离为 2 的顶点，以此类推

**算法步骤**：

1. 将起始顶点放入队列，标记为已访问
2. 当队列非空时，取出队首顶点，访问其所有未访问的邻接顶点，标记它们并加入队列
3. 重复步骤 2 直到队列为空

**应用**：

- 寻找无权图中的最短路径
- 寻找连通分量

**时间复杂度**：O(|V| + |E|)

### 2.3 Dijkstra 算法

**问题定义**：

- 单源最短路径问题：给定一个带权有向图和一个源顶点，找出从源顶点到所有其他顶点的最短路径

**算法思想**：

- 贪心策略，每次选择当前距离源点最近的未处理顶点

**算法步骤**：

1. 初始化：将源顶点的距离设为 0，其他顶点的距离设为无穷大
2. 创建一个集合 S 包含已处理的顶点，初始为空
3. 当 S 不包含所有顶点时：
   - 选择不在 S 中且距离最小的顶点 u
   - 将 u 加入 S
   - 更新 u 的所有邻接顶点的距离

**限制**：

- 只适用于所有边权重为非负的图

**时间复杂度**：

- 使用二叉堆：O((|V| + |E|) log |V|)
- 使用斐波那契堆：O(|E| + |V| log |V|)

### 2.4 Bellman-Ford 算法

**问题定义**：

- 单源最短路径问题，可处理含有负权边的图

**算法思想**：

- 通过对所有边进行多次松弛操作，逐步找到最短路径

**算法步骤**：

1. 初始化：将源顶点的距离设为 0，其他顶点的距离设为无穷大
2. 对所有边进行|V|-1 次松弛操作
3. 检查是否存在负权环：如果再进行一次松弛操作后有距离变小，则存在负权环

**应用**：

- 处理含有负权边的图的最短路径问题
- 检测负权环

**时间复杂度**：O(|V| × |E|)

## 总结

这些算法覆盖了课程中的两大主要类别：分治法和图论。分治法通过将问题分解为更小的子问题来解决复杂问题，而图论算法则处理由顶点和边组成的图结构中的各种问题。这些算法构成了计算机科学中算法设计与分析的基础，为解决各种实际问题提供了强大的工具。
