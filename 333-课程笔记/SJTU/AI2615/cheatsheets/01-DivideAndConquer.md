# Cheatsheet 1: 分治法 (Divide and Conquer)

## 1. 分治策略基本思想 (General Idea)

分治法是一种解决问题的算法策略，主要包含三个步骤：

1.  **分解 (Divide)**：将原问题分解为若干个规模较小、相互独立、与原问题形式相同的子问题。
2.  **解决 (Conquer)**：若子问题规模足够小，则直接求解，否则递归地解决各子问题。
3.  **合并 (Combine)**：将各子问题的解合并为原问题的解。

## 2. 渐进符号 (Asymptotic Notation)

用于描述算法运行时间的增长趋势。

- **Big O (上界)**：$T(n) = O(g(n))$ 表示存在常数 $C>0$ 和 $n_0$，使得对所有 $n > n_0$，有 $T(n) \le C \cdot g(n)$。
- **Big Ω (下界)**：$T(n) = \Omega(g(n))$ 表示存在常数 $C>0$ 和 $n_0$，使得对所有 $n > n_0$，有 $T(n) \ge C \cdot g(n)$。
- **Big Θ (紧界)**：$T(n) = \Theta(g(n))$ 当且仅当 $T(n) = O(g(n))$ 且 $T(n) = \Omega(g(n))$。
- **Little o (严格上界)**：$T(n) = o(g(n))$ 表示对**任意**常数 $C>0$，存在 $n_0$，使得对所有 $n > n_0$，有 $T(n) < C \cdot g(n)$。
- **Little ω (严格下界)**：$T(n) = \omega(g(n))$ 表示对**任意**常数 $C>0$，存在 $n_0$，使得对所有 $n > n_0$，有 $T(n) > C \cdot g(n)$。

## 3. 主定理 (Master Theorem)

用于求解形如 $T(n) = aT(n/b) + O(n^d)$ 的递归关系式。

设 $a \ge 1, b > 1$ 为常数，$f(n)$ 为函数，$T(n)$ 定义为 $T(n) = aT(n/b) + f(n)$。以 $f(n) = O(n^d)$ 为例：

- 若 $a < b^d$ (或 $\log_b a < d$)，则 $T(n) = O(n^d)$。
- 若 $a = b^d$ (或 $\log_b a = d$)，则 $T(n) = O(n^d \log n)$。
- 若 $a > b^d$ (或 $\log_b a > d$)，则 $T(n) = O(n^{\log_b a})$。

**理解**: 比较 $a$ (子问题数量) 和 $b^d$ (每个子问题规模减小带来的合并/分解代价变化)。$n^{\log_b a}$ 是所有叶子节点的总代价，$n^d$ 是根节点的代价。

- $a < b^d$：根节点代价占主导。
- $a = b^d$：每层代价大致相同。
- $a > b^d$：叶子节点代价占主导。

## 4. 具体算法示例 (Examples)

### 4.1 整数乘法 (Integer Multiplication)

**问题**: 计算两个 n 位大整数 $x, y$ 的乘积。

- **标准算法 (小学乘法)**：$O(n^2)$。
- **简单分治**:
  - 将 n 位数 $x$ 分解为 $a \cdot 10^{n/2} + b$，将 $y$ 分解为 $c \cdot 10^{n/2} + d$。
  - $xy = ac \cdot 10^n + (ad+bc) \cdot 10^{n/2} + bd$。
  - 需要计算 4 个 $n/2$ 位的乘法 (ac, ad, bc, bd)。
  - 递归式: $T(n) = 4T(n/2) + O(n)$。
  - 复杂度: $O(n^{\log_2 4}) = O(n^2)$，没有改进。
- **Karatsuba 算法 (1960)**：
  - 同样分解 $x, y$。
  - 计算 $P_1 = ac$, $P_2 = bd$, $P_3 = (a+b)(c+d)$。
  - $ad+bc = P_3 - P_1 - P_2$。
  - 只需要 3 个 $n/2$ 位的乘法。
  - 递归式: $T(n) = 3T(n/2) + O(n)$。
  - 复杂度: $O(n^{\log_2 3}) \approx O(n^{1.585})$。
- **更快算法**: Toom-Cook ($O(n^{1.465})$), Schönhage–Strassen (FFT, $O(n \log n \log \log n)$), Harvey-Hoeven ($O(n \log n)$)。

### 4.2 归并排序 (Merge Sort)

**问题**: 对 n 个数进行排序。

- **算法步骤**：
  1.  **分解 (Divide)**：将包含 n 个元素的序列分成两个各有 $n/2$ 个元素的子序列。
  2.  **解决 (Conquer)**：递归地对两个子序列进行归并排序。
  3.  **合并 (Combine)**：合并两个已排序的子序列得到排序结果。
- **合并操作 (Merge)**：
  - 使用双指针法，线性时间 ($O(n)$) 合并两个已排序的子序列。
- **复杂度**:
  - 递归式: $T(n) = 2T(n/2) + O(n)$。
  - 根据主定理 ($a=2, b=2, d=1$, $a=b^d$)，时间复杂度为 $O(n \log n)$。

### 4.3 计算逆序对 (Counting Inversions)

**问题**: 给定一个序列 $x_1, x_2, \dots, x_n$，计算逆序对的数量，即满足 $i < j$ 但 $x_i > x_j$ 的数对 $(i, j)$ 的数量。

- **暴力法**: $O(n^2)$。
- **分治法 (类归并排序)**：
  1.  **分解 (Divide)**：将序列分成左右两半。
  2.  **解决 (Conquer)**：递归计算左半部分的逆序对数 $c_1$ 和右半部分的逆序对数 $c_2$。
  3.  **合并 (Combine)**：计算跨越左右两半的逆序对数 $c_3$ (即一个数在左半部分，另一个在右半部分形成的逆序对)。总逆序对 = $c_1 + c_2 + c_3$。
- **合并并计算跨界逆序对 (Merge and Count)**：
  - 在合并两个已排序子序列 $A$ 和 $B$ 的过程中计算 $c_3$。
  - 当从 $B$ 中取元素 $b_j$ 放入合并后序列时，说明 $A$ 中当前指针 $i$ 及之后的所有元素 $a_k$ ($k \ge i$) 都比 $b_j$ 大，形成逆序对。此时增加计数 $c_3$ += (A 中剩余元素个数) (注意：PPT 中的伪代码逻辑似乎是当从 A 取元素时计数，需要核对)。
  - 合并和计数过程可在 $O(n)$ 时间内完成。
- **复杂度**:
  - 递归式: $T(n) = 2T(n/2) + O(n)$。
  - 时间复杂度为 $O(n \log n)$。

### 4.4 选择问题 (Selection Problem)

**问题**: 在 n 个数中找到第 k 小的元素。

- **排序法**: 先排序，再取第 k 个元素。$O(n \log n)$。
- **Quick Select (随机化)**：
  1.  **分解 (Divide)**：随机选择一个主元 (pivot) $v$。将数组划分为三个部分：小于 $v$ 的 $L$，等于 $v$ 的 $M$，大于 $v$ 的 $R$。
  2.  **解决 (Conquer)**：
      - 如果 $k \le |L|$，则递归在 $L$ 中找第 k 小的元素。
      - 如果 $|L| < k \le |L| + |M|$，则 $v$ 就是第 k 小的元素。
      - 如果 $k > |L| + |M|$，则递归在 $R$ 中找第 $k - |L| - |M|$ 小的元素。
- **复杂度 (Quick Select)**：
  - 最坏情况：每次选到最大或最小元素，$T(n) = T(n-1) + O(n) = O(n^2)$。
  - 期望情况：每次划分比较均衡 (pivot 在中间 1/2 区域的概率是 1/2)，$E[T(n)] = O(n)$。
- **Median of Medians (确定性线性时间)**：
  1.  **选择 Pivot**:
      - 将 n 个数分成 $\lceil n/5 \rceil$ 组，每组 5 个数。
      - 找到每组的中位数 (常数时间)。
      - 递归调用选择算法找到这些中位数的中位数 $v$ (作为 Pivot)。
  2.  **分解**: 用 pivot $v$ 划分数组为 $L, M, R$。
  3.  **解决**: 同 Quick Select。
- **复杂度 (Median of Medians)**：
  - 选择 Pivot 的代价是 $T(n/5) + O(n)$。
  - 保证 Pivot 至少比 $3n/10$ 个数大，且至少比 $3n/10$ 个数小。
  - 因此，递归的子问题大小最多为 $n - 3n/10 = 7n/10$。
  - 递归式: $T(n) \le T(n/5) + T(7n/10) + O(n)$。
  - 解得 $T(n) = O(n)$。

### 4.5 平面最近点对 (Closest Pair)

**问题**: 在 n 个二维平面点中，找到距离最近的两个点。

- **暴力法**: $O(n^2)$。
- **一维情况**: 排序后比较相邻点，$O(n \log n)$。
- **分治法 (二维)**：
  1.  **预处理**: 创建两个数组，分别按 x 坐标和 y 坐标排序 ($P_x, P_y$)。这一步耗时 $O(n \log n)$。
  2.  **分解 (Divide)**：根据 $P_x$ 的中位数找到垂直分割线 $L$，将点集 $P$ 分为左右两半 $P_L, P_R$。同时将 $P_y$ 也划分为 $P_{yL}, P_{yR}$ ($O(n)$)。
  3.  **解决 (Conquer)**：递归地找到 $P_L$ 中的最近距离 $\delta_L$ 和 $P_R$ 中的最近距离 $\delta_R$ ($2T(n/2)$)。
  4.  **合并 (Combine)**：
      - 令 $\delta = \min(\delta_L, \delta_R)$。
      - 关键在于处理跨越分割线 $L$ 的点对。只需要考虑距离分割线 $L$ 左右 $\delta$ 范围内的点 (形成一个 $2\delta$ 宽的条带，Strip)。
      - 令 $S'$ 为条带内的点，按 y 坐标排序 (利用预处理的 $P_y$ 可以在 $O(n)$ 内得到)。
      - 对于 $S'$ 中的每个点 $p$，只需要检查其后**有限个** (理论上最多 7 个，实践中可能是 6 或其他小常数) 在 y 坐标上接近它的点 $q$ (距离小于 $\delta$)，看是否有 $d(p,q) < \delta$。可以证明这样的点 $q$ 必定落在以 $p$ 为参考的一个 $2\delta \times \delta$ (或 $\delta \times 2\delta$) 的矩形内，并且由于左右两边内部点对距离不小于 $\delta$，这个矩形内点的数量是常数。
      - 合并步骤可在 $O(n)$ 时间内完成 (如果预处理了 $P_y$)。
- **复杂度**:
  - 如果每次合并都对条带内的点按 y 排序：$T(n) = 2T(n/2) + O(n \log n)$，解得 $T(n) = O(n \log^2 n)$。
  - 通过预处理按 y 排序的数组并在递归中维护它，合并步骤可优化至 $O(n)$：$T(n) = 2T(n/2) + O(n)$，解得 $T(n) = O(n \log n)$。

### 4.6 快速傅里叶变换 (Fast Fourier Transform - FFT)

**问题**: 快速计算多项式乘法 $R(x) = P(x)Q(x)$。$P(x)$ 和 $Q(x)$ 的度数最高为 $d-1$，$R(x)$ 度数最高为 $2d-2$。

- **思路**: 利用多项式的点值表示法。一个度数为 $n-1$ 的多项式可以由 n 个不同的点 $(x_i, y_i)$ 唯一确定。
- **FFT 框架**：
  1.  **求值 (Evaluation / Interpolation / FFT)**: 选择 $D = 2d-1$ (通常取 $\ge 2d-1$ 的最小 2 的幂次) 个特殊点（D 次单位复数根 $\omega^0, \omega^1, \dots, \omega^{D-1}$，其中 $\omega = e^{2\pi i / D}$）。计算 $P(x)$ 和 $Q(x)$ 在这 D 个点上的值。
  2.  **点值乘法 (Pointwise Multiplication)**: 计算 $R(\omega^k) = P(\omega^k) Q(\omega^k)$ for $k = 0, \dots, D-1$。
  3.  **插值 (Interpolation / Inverse FFT)**: 根据 $R(x)$ 的 D 个点值 $((\omega^k, R(\omega^k)))$，恢复出 $R(x)$ 的系数 $c_0, \dots, c_{D-1}$。
- **快速求值 (FFT 算法)**：
  - 利用**奇偶分解**: $P(x) = P_e(x^2) + x P_o(x^2)$，其中 $P_e$ 包含偶数项系数，$P_o$ 包含奇数项系数。
  - 计算 $P(\omega^k)$ 和 $P(\omega^{k+D/2})$ ($k=0, \dots, D/2-1$)。因为 $(\omega^{k+D/2})^2 = (\omega^k)^2 = \omega^{2k}$ 且 $\omega^{k+D/2} = -\omega^k$，所以：
    - $P(\omega^k) = P_e(\omega^{2k}) + \omega^k P_o(\omega^{2k})$
    - $P(\omega^{k+D/2}) = P_e(\omega^{2k}) - \omega^k P_o(\omega^{2k})$
  - 递归计算 $P_e$ 和 $P_o$ 在 $D/2$ 个点 $(\omega^0, \omega^2, \dots, \omega^{D-2})$ 上的值。
  - 递归式: $T(D) = 2T(D/2) + O(D)$。
  - 复杂度: $O(D \log D) = O(d \log d)$。
- **快速插值 (Inverse FFT)**：
  - 求值过程可以表示为矩阵向量乘法 $\mathbf{y} = A(\omega) \mathbf{c}$，其中 $\mathbf{y}$ 是点值向量，$\mathbf{c}$ 是系数向量，$A(\omega)$ 是范德蒙德矩阵，其 $(k, j)$ 元素是 $(\omega^k)^j$。
  - 插值即求解 $\mathbf{c} = A(\omega)^{-1} \mathbf{y}$。
  - 可以证明 $A(\omega)^{-1} = \frac{1}{D} A(\omega^{-1})$。
  - 因此，计算逆 FFT 等价于用 $\omega^{-1}$ (即 $\overline{\omega}$) 作为单位根进行一次 FFT，然后将结果除以 D。
  - 复杂度: $O(D \log D) = O(d \log d)$。
- **多项式乘法总复杂度**: $O(d \log d)$ (求值) + $O(d)$ (点值乘法) + $O(d \log d)$ (插值) = $O(d \log d)$。
