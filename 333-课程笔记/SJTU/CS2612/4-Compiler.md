## 拆分复合表达式

拆分前：`x = y*y + z*z`

拆分后：

```
#0 = y * y
#1 = z * z
x = #0 + #1
```

要注意：

1. 关键点 1：每个赋值语句至多进行一步计算（这里的计算包括从内存读取数值）（这里上课用L1.h代码说明我们需要拆分后的数据结构）
2. 关键点 2：转化后的程序仅在必要处保留树结构（可以想像，汇编代码是不需要树结构的）TODO：那什么是“必要保留树结构”？

对表达式语法树做递归操作

上课例子：`(y*y + z*z) * 4`

top-level来看是两个子表达式用乘号连接，分别是`(y*y + z*z)`和`4`

前者对应：

```
#1 = y * y
#2 = z * z
#1 + #2
```

后者对应

```
4
```

合并的时候观察有没有计算操作（？没听见这里怎么说的），反正类似左子表达式`#1 + #2`这个样子就是需要我们添加`#3`来合并：

```
#1 = y * y
#2 = z * z
#3 = #1 + #2
#3 * 4
```

上面这个是表达式层面的，后续我们还要探讨程序语句层面的

> 表达式我们可以很自然的得到赋值语句的拆分

3. 关键点 3：要妥善处理 while 循环条件的计算语句

拆分前：

```
x + y + z < 10
```

（假设）拆分后：

```
#0 = x + y
#1 = #0 + z
#1 < 10
```

这个对于if语句是没有问题的，但是while就更加复杂，因为while是每一次都要计算判定。

### 简单寄存器分配算法

> 注意这个问题是找不到绝对最优的

假设共有 K 个寄存器；

步骤一，Simplify：在 interference graph 中删除度数 K-1 的节点，删除的节点用栈记录；

为什么？K-1说明和它冲突的变量非常少（？），我们最后给它分配寄存器。

步骤二，Spill：如果无法 Simplify，就任意删除一个节点，再回到前面步骤一；

步骤三，Select：按照删除节点的倒序为所有变量分配寄存器；

> 注：Simplify 删除的节点能够保证被分配到与 interference graph 上相邻节点不冲突的寄存器，Spill 变量可能可以分配到寄存器（假 Spill），也可能无法分配到寄存器（真 Spill），此时应当存储在内存中；
