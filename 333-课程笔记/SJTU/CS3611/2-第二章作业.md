# 简答题

## 第一题

判断正误并简要阐述原因：

- A. 两个不同的 Web 页面可以通过同一个持续连接发送。
- B. 在浏览器和初始服务器之间使用非持续连接的话，一个 TCP 报文段是可能携带两个不同的 HTTP 服务请求报文的。
- C. 在 HTTP 响应报文中的 Date：首部指出了该响应中对象最后一次修改的时间。
- D. HTTP 响应报文决不会具有空的报文体。

### 答案

- A. 正确。HTTP/1.1 支持持续连接，允许多个请求-响应对通过同一个 TCP 连接发送，不需要为每个对象建立新连接。
- B. 错误。在非持续连接中，每个 TCP 连接只用于传输一个请求-响应对，连接关闭后才会建立新连接。TCP 连接关闭后，不可能在同一个 TCP 报文段中携带两个不同的 HTTP 请求。
- C. 错误。HTTP 响应报文中的 Date 字段表示响应生成的时间，而不是对象最后修改的时间。对象最后修改时间由 Last-Modified 字段指示。
- D. 错误。某些 HTTP 响应如 204 No Content、304 Not Modified 等状态码的响应通常没有报文体，只有响应头。

## 第二题

考虑一条 10 米短链路，某发送方经过它能够以 $150$ bps 速率双向传输。假定包含数据的分组是 $10^5$ bit，仅包含控制（如 ACK 或握手）的分组是 200 比特长。现在考虑 HTTP 协议，初始下载对象包含 10 个来自相同发送方的引用对象，并且假定每个下载对象是 $10^5$ bit。在这种情况下，经非持续 HTTP 的并行实例的并行下载有意义吗？现在考虑持续 HTTP，你期待这比非持续的情况有很大增益吗？计算并解释你的答案（假定 N 个并行连接每个都获得 $\frac{1}{N}$ 的链路带宽）。

### 答案

链路传输速率：$150$ bps
数据分组大小：$10^5$ bits
控制分组大小：200 bits
对象数量：1 个初始对象 + 10 个引用对象

非持续 HTTP，每个对象需要：

- TCP 连接建立：3 个控制分组（SYN, SYN+ACK, ACK）
- HTTP 请求-响应：1 个请求分组(假设为控制分组大小) + 1 个响应分组(数据分组)
- TCP 连接关闭：4 个控制分组（FIN, ACK, FIN, ACK）

每个对象总时间 = $(3+1+4) \times \frac{200}{150} + \frac{10^5}{150} \approx 10.7$ 秒
11 个对象总时间 = $11 \times 10.7 \approx 117.7$ 秒

并行非持续 HTTP（假设 11 个并行连接）：
每个连接带宽 = $\frac{150}{11} \approx 13.6$ bps
每个对象时间 = $(3+1+4) \times \frac{200}{13.6} + \frac{10^5}{13.6} \approx 117.7$ 秒

持续 HTTP：

- TCP 连接建立：3 个控制分组
- 11 个 HTTP 请求-响应：11×(1 个请求分组 + 1 个响应分组)
- TCP 连接关闭：4 个控制分组

总时间 = $3 \times \frac{200}{150} + 11 \times (\frac{200}{150} + \frac{10^5}{150}) + 4 \times \frac{200}{150} \approx 7.3 + 11 \times 667.3 + 5.3 \approx 7358.9$ 秒

持续 HTTP 明显优于非持续 HTTP，因为只需要一次 TCP 连接建立和关闭过程。并行非持续连接没有明显优势，因为带宽被均分，总传输时间基本相同。

## 第三题

假设你所在系具有一台用于系里所有计算机的本地 DNS 服务器。你是普通用户（即你不是网络/系统管理员）。你能够确定是否在几秒前从你系里的一台计算机可能访问过一台外部 Web 站点吗？解释原因。

### 答案

不能确定。作为普通用户，你无法访问本地 DNS 服务器的缓存或日志信息，这些通常只有系统管理员才有权限查看。DNS 服务器会缓存最近的查询结果，但普通用户无法查看这些缓存内容。即使 DNS 服务器最近解析过某网站的域名，作为普通用户也无法得知这一信息。此外，即使能看到 DNS 查询记录，也只能知道域名被解析，但不能确定是否实际访问了该网站。

### 1. 实现多线程服务器

```python
import socket
import sys
import threading

def handle_client(connectionSocket, addr):
    try:
        message = connectionSocket.recv(1024).decode()
        filename = message.split()[1]
        f = open(filename[1:])
        outputdata = f.readlines()

        connectionSocket.send("HTTP/1.1 200 OK\r\n".encode())
        connectionSocket.send("Content-Type: text/html\r\n\r\n".encode())

        for i in range(0, len(outputdata)):
            connectionSocket.send(outputdata[i].encode())

        connectionSocket.send("\r\n".encode())
        connectionSocket.close()
    except IOError:
        connectionSocket.send("HTTP/1.1 404 Not Found\r\n".encode())
        connectionSocket.send("Content-Type: text/html\r\n\r\n".encode())
        connectionSocket.send("<html><head></head><body><h1>404 Not Found</h1></body></html>\r\n".encode())
        connectionSocket.close()

serverSocket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
serverPort = 9876
serverSocket.bind(('', serverPort))
serverSocket.listen(5)  # 增加了队列长度

print(f"Server started on port {serverPort}")

while True:
    print('Ready to serve...')
    connectionSocket, addr = serverSocket.accept()
    print(f"Connection from {addr}")

    # 创建新线程处理客户端请求
    client_thread = threading.Thread(target=handle_client, args=(connectionSocket, addr))
    client_thread.start()

serverSocket.close()
sys.exit()
```

这个多线程服务器我们运行在`9876`端口上，和之前的单线程服务器一样。我们可以通过下面这个`test_requests.sh`脚本搭配`time`命令来测试单线程/多线程服务器的性能有什么区别：

### 2. 编写 HTTP 客户端

客户端代码可以参考附件里面的`client.py`，或者下面的代码：

```python
import socket
import sys

def http_client(server_host, server_port, filename):
    try:
        client_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        client_socket.connect((server_host, server_port))
        request = f"GET /{filename} HTTP/1.1\r\nHost: {server_host}\r\n\r\n"
        client_socket.send(request.encode())

        response = b""
        while True:
            data = client_socket.recv(4096)
            if not data:
                break
            response += data

        client_socket.close()

        print(response.decode())

    except Exception as e:
        print(f"Error: {e}")
        sys.exit(1)

if __name__ == "__main__":
    if len(sys.argv) != 4:
        print("Usage: python client.py server_host server_port filename")
        sys.exit(1)

    server_host = sys.argv[1]
    server_port = int(sys.argv[2])
    filename = sys.argv[3]

    http_client(server_host, server_port, filename)
```
