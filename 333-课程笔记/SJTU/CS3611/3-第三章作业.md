# Lab 3-TCP 拥塞控制与公平性实验

## 实验内容：

1. 实验环境搭建

- 使用网络仿真工具（如 ns-3、Mininet）或真实网络环境（推荐 Wireshark 抓包分析）。
- 设计一个简单的网络拓扑：两个发送方（TCP 流）通过一个带宽受限的瓶颈链路连接到一个接收方。

2. 实验步骤

**单 TCP 流实验：**

1. 启动单个 TCP 流（如 TCP Cubic），观察拥塞窗口（cwnd）随时间的增长（慢启动 → 拥塞避免）。
2. 在链路中人为引入丢包（如使用 tc 命令模拟丢包率），观察快速重传/快速恢复机制。

**多 TCP 流实验：**

1. 同时启动两个相同类型的 TCP 流（如两个 Cubic 流），观察它们的带宽分配是否公平。
2. 混合不同类型 TCP 流（如一个 Cubic 和一个 Reno），分析公平性问题。

3. 数据分析

- 使用 tcpdump 或 Wireshark 抓包，提取 cwnd 和吞吐量数据。
- 绘制 cwnd 随时间变化曲线，对比不同阶段的行为（如慢启动指数增长、拥塞避免线性增长）。
- 计算多流场景下各流的公平性指数（如 Jain's Fairness Index）。
