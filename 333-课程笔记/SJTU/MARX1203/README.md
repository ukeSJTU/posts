# 重要时间点

## 一、新民主主义革命时期（1919-1949）

**1919年** - 五四运动，新民主主义革命的开端

**1921年7月** - 中国共产党第一次全国代表大会在上海召开，中国共产党成立

**1927年8月1日** - 南昌起义，人民军队诞生

**1927年9月** - 秋收起义，毛泽东提出"枪杆子里出政权"

**1927年10月** - 井冈山革命根据地建立，开辟农村包围城市道路

**1935年1月** - 遵义会议，确立毛泽东在党中央的领导地位

**1936年10月** - 红军三大主力会师，长征胜利结束

**1937年7月7日** - 卢沟桥事变，全面抗战爆发

**1945年** - 中共七大，确立毛泽东思想为党的指导思想

**1949年10月1日** - 中华人民共和国成立

## 二、社会主义革命和建设时期（1949-1978）

**1949-1952年** - 新民主主义向社会主义过渡时期

**1953年** - 提出过渡时期总路线，开始社会主义改造

**1956年** - 三大改造基本完成，社会主义制度基本建立

**1956年** - 中共八大召开，正确分析国内主要矛盾

**1957年** - 《关于正确处理人民内部矛盾的问题》发表

**1958年** - "大跃进"运动和人民公社化运动开始

**1966-1976年** - "文化大革命"十年

**1976年10月** - 粉碎"四人帮"，"文化大革命"结束

**1978年5月** - 真理标准问题大讨论开始

## 三、改革开放和社会主义现代化建设新时期（1978-2012）

### 邓小平理论形成时期

**1978年12月** - 十一届三中全会，改革开放开启，工作重心转移到经济建设

**1979年** - 设立深圳、珠海、汕头、厦门四个经济特区

**1980年** - 提出"四项基本原则"

**1982年** - 中共十二大，提出"建设有中国特色的社会主义"

**1984年** - 十二届三中全会，经济体制改革全面展开

**1987年** - 中共十三大，系统阐述社会主义初级阶段理论

**1992年** - 邓小平南方谈话，明确社会主义市场经济方向

**1992年10月** - 中共十四大，确立社会主义市场经济体制改革目标

**1997年** - 中共十五大，确立邓小平理论为党的指导思想

### "三个代表"重要思想形成时期

**2000年2月** - 江泽民首次完整提出"三个代表"重要思想

**2001年** - 中国加入世界贸易组织（WTO）

**2002年11月** - 中共十六大，确立"三个代表"重要思想为党的指导思想

### 科学发展观形成时期

**2003年** - 胡锦涛提出科学发展观

**2007年10月** - 中共十七大，科学发展观写入党章

**2012年11月** - 中共十八大，确立科学发展观为党的指导思想

## 四、中国特色社会主义新时代（2012-至今）

### 习近平新时代中国特色社会主义思想形成时期

**2012年11月** - 中共十八大，中国特色社会主义进入新时代

**2013年** - 提出"一带一路"倡议

**2013年11月** - 十八届三中全会，全面深化改革

**2017年10月** - 中共十九大，确立习近平新时代中国特色社会主义思想为党的指导思想

**2018年3月** - 十三届全国人大一次会议，习近平新时代中国特色社会主义思想写入宪法

**2020年** - 全面建成小康社会目标实现

**2021年7月1日** - 庆祝中国共产党成立100周年

**2021年11月** - 十九届六中全会，通过第三个历史决议

**2022年10月** - 中共二十大，开启全面建设社会主义现代化国家新征程
