### **时序分析三步法**

1. **找到起点**：在同步电路中，所有的变化都源于**时钟的有效边沿**（在这个题目里是上升沿）。所以，我们的分析起点永远是那些由时钟直接控制的元件——**寄存器**。在时钟“滴答”一下之后，信号最先从寄存器的输出端 Q 跑出来。
2. **追踪路径，累加延迟**：从寄存器的 Q 端出发，像侦探一样顺着导线追踪信号的去向。每经过一个元件（比如逻辑门、加法器、乘法器），信号的到达时间就会增加。你要做的就是将这个元件自身的**传播延迟 (propagation delay)** 累加到信号已经花费的时间上。
3. **处理汇合点**：当多条不同的路径汇合到一个元件的输入端时（比如一个加法器的两个输入端），你必须遵循一个黄金法则：**“木桶原理”**。这个元件必须等到**所有输入信号中最晚到达的那个**准备好之后，才能开始它自己的计算。所以，在汇合点，我们总是取所有输入路径延迟中的**最大值**，然后再累加当前元件的延迟。

### **Q1.8: 最长的组合逻辑延迟**

这个问题是计算后续所有问题的基础，所以我们先来解决它。

**思路**：我们要找到从**一个寄存器的Q端**出发，到**另一个（或同一个）寄存器的D端**结束的所有路径，计算这些路径上**纯组合逻辑元件**（非寄存器）的总延迟，然后找出其中的最大值。

我们来识别一下所有的路径：

- **路径1**: 上寄存器Q -> Wire A -> 加法器 -> Wire C -> 乘法器 -> Wire E -> 上寄存器D
  - 组合逻辑部分: 加法器 + 乘法器
  - 延迟: 10ns + 15ns = 25ns
- **路径2**: 上寄存器Q -> Wire A -> 加法器 -> Wire C -> 乘法器 -> Wire E -> 下寄存器D
  - 组合逻辑部分: 加法器 + 乘法器
  - 延迟: 10ns + 15ns = 25ns
- **路径3**: 下寄存器Q -> Wire B -> 加法器 -> Wire C -> 乘法器 -> Wire E -> 上寄存器D
  - 组合逻辑部分: 加法器 + 乘法器
  - 延迟: 10ns + 15ns = 25ns
- **路径4**: 下寄存器Q -> Wire B -> 加法器 -> Wire C -> 乘法器 -> Wire E -> 下寄存器D
  - 组合逻辑部分: 加法器 + 乘法器
  - 延迟: 10ns + 15ns = 25ns
- **路径5**: 下寄存器Q -> Wire B -> 非门 -> Wire D -> 上寄存器D
  - 组合逻辑部分: 非门
  - 延迟: **1 ns**

我们比较所有路径的组合逻辑延迟：25ns 和 1ns。  
最长的是 **25 ns**。

### **Q1.9: 最短的时钟周期**

**思路**：这个就是我们之前总结的**关键路径**公式！  
T_min ≥ clk-to-q延迟 + 最长的组合逻辑延迟 + 建立时间

我们把值代进去：

- clk-to-q延迟 = **2 ns**
- 最长的组合逻辑延迟 (来自 Q1.8) = **25 ns**
- 建立时间 (setup time) = **5 ns**

T_min ≥ 2ns + 25ns + 5ns = 32ns

所以，为了让电路能正常工作，时钟周期最短也得是 **32 ns**。

---

### **Q1.7: 最大的保持时间**

**思路**：这个问题是考察**最短路径约束**。  
clk-to-q延迟 + 最短的组合逻辑延迟 ≥ 保持时间 (Hold Time)

这个公式告诉我们，为了电路稳定，保持时间不能无限大，它必须小于等于信号从一个寄存器出发，跑完最短组合路径到达下一个寄存器的时间。

我们同样把值代进去：

- clk-to-q延迟 = **2 ns**
- 最短的组合逻辑延迟：我们刚才识别了所有路径，最短的组合逻辑延迟来自路径5，只有那个**非门**，延迟是 **1 ns**。

Hold Time ≤ 2ns + 1ns = 3ns

所以，为了电路能正常工作，寄存器的保持时间最大不能超过 **3 ns**。

**总结一下答案**:

- **Q1.8 (最长组合逻辑延迟)**: **25 ns**
- **Q1.9 (最短时钟周期)**: **32 ns**
- **Q1.7 (最大保持时间)**: **3 ns**
