下面这个是我最一开始自己想出来的解法：

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int i = 0, j = prices.size() - 1;
        int i_min = prices[i], j_max = prices[j];
        for (; i <= j; i++, j--) {
            if (prices[i]<i_min) {
                i_min = prices[i];
            }
            if (prices[j] > j_max) {
                j_max = prices[j];
            }
        }
        int max_profit = j_max - i_min;
        return max_profit > 0 ? max_profit : 0;
    }
};
```

尽管这个通过了两个样例测试，但这个是错误的，思考为什么？

反例：

```text
prices = [3,2,6,5,0,3]
expected = 6-2 = 4
output = 3
```

正确答案：

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int inf = 1e9;
        int minprice = inf, maxprofit = 0;
        for (int price: prices) {
            maxprofit = max(maxprofit, price - minprice);
            minprice = min(price, minprice);
        }
        return maxprofit;
    }
};
```

简单来说就是在遍历的过程中，顺带记录前n-1天最小值，然后每次都假设是在第n天买入的话，利润是多少并和当前最大利润比较。
