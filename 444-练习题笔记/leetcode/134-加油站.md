思路分析：贪心，遍历数组，依此看从每个加油站出发是否能够完成一周。

但是实际上，可以加快判断，也就是说便利的过程中，假如走到某个加油站发现无法继续（油不够了），则下一次直接从这个加油站开始尝试。

x出发最远到达y，无法到达y+1，那么x与y之间任意一点出发，都无法到达y+1，所以重新寻找出发点时，直接从y+1出发即可。  
反证法：假设xy之间存在一点k，能够到达y+1。  
那么必有k到y的（gas-cost）累加和>=0。又因为x出发无法到达y+1，xy整体的累加和小于等于0，从而推出另一部分x到k-1的（gas-cost）累加和小于等于0。  
如果x到k-1的累加和小于0，说明x无法到达k，与x出发能到达y相矛盾，因为x出发到达y必然能够到达中间点k。  
如果x到k-1的累加和等于0，说明x恰好到达k，此时油量为0，k出发和x出发是等价的，而此时k到y累加和>=0，说明k能到达y+1，x也能够到达y+1，这和题设矛盾。  
综上所述，假设不成立。

```cpp
class Solution {
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost) {
        int n = gas.size();
        int i = 0;
        while (i < n) {
            int sumOfGas = 0, sumOfCost = 0;
            int cnt = 0;
            while (cnt < n) {
                int j = (i + cnt) % n;
                sumOfGas += gas[j];
                sumOfCost += cost[j];
                if (sumOfCost > sumOfGas) {
                    break;
                }
                cnt++;
            }
            if (cnt == n) {
                return i;
            } else {
                i = i + cnt + 1;
            }
        }
        return -1;
    }
};
```

class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int temp = 0;
        int ans = -1;
        int sum = 0;
        for (int i = 0; i < gas.length; i++) {
            temp += gas[i] - cost[i];
            sum += gas[i] - cost[i];
            if (sum < 0) {
                ans = i;
                sum = 0;
            }
        }
        if (temp < 0) {
            return -1;
        }
        return ans + 1;
    }
}
