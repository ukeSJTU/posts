## 题目描述 (Problem Description)

给你两个字符串：`ransomNote` 和 `magazine` ，判断 `ransomNote` 能不能由 `magazine` 里面的字符构成。

如果可以，返回 `true` ；否则返回 `false` 。

`magazine` 中的每个字符只能在 `ransomNote` 中使用一次。

**示例 1：**

**输入：**ransomNote = "a", magazine = "b"
**输出：**false

**示例 2：**

**输入：**ransomNote = "aa", magazine = "ab"
**输出：**false

**示例 3：**

**输入：**ransomNote = "aa", magazine = "aab"
**输出：**true

**提示：**

- `1 <= ransomNote.length, magazine.length <= 10^5`
- `ransomNote` 和 `magazine` 由小写英文字母组成

## 首次尝试思路 (My Initial Attempts)

### 第一次尝试 (Attempt 1)

- **我的思路:**
  - ransomNote生成一个哈希表，key是字符，value是字符出现次数
  - magazine生成另一个哈希表，key是字符，value是字符出现次数
  - 比较ransomNote里面的每一个字符出现次数是否小于等于magazine里面每一个字符出现次数

```python
class Solution:
    def convert(self, original_str: str) -> dict:
        h = dict()
        for c in original_str:
            if c in h:
                h[c] += 1
            else:
                h[c] = 1
        return h
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        ransomHashtable = self.convert(ransomNote)
        magazineHashtable = self.convert(magazine)

        for k, v in ransomHashtable.items():
            if v > magazineHashtable.get(k, 0):
                return False

        return True
```

- **结果:** AC，但是感觉效率不够高，27ms

from collections import Counter
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        if len(ransomNote) > len(magazine):
            return False
        return Counter(ransomNote) <= Counter(magazine)

关于哈希表类型的题目，我觉得一个经常出现的模式就是把原始数据转换成对应的哈希表，例如上面第一次尝试中`convert`函数：

```python
def convert(self, original_str: str) -> dict:
	h = dict()
	for c in original_str:
		if c in h:
			h[c] += 1
		else:
			h[c] = 1
	return h
```

但是更好的写法可以是：

```python
def convert(self, original_str: str) -> dict:
    h = dict()
    for c in original_str:
        h[c] = h.get(c, 0) + 1
    return h
```

甚至可以利用python内置的功能：

```python
def convert(self, original_str: str) -> dict:
    from collections import Counter
    return Counter(original_str)
```

> 这个似乎效率更高一些，仅仅替换`convert`函数后，15ms。
> Counter底层用C实现，速度很快，专为计数场景优化。下面列出Counter的基本使用方法

### `Counter`使用方法

#### 导入和创建

```python
from collections import Counter

# 从字符串创建
counter1 = Counter("hello")
print(counter1)  # Counter({'l': 2, 'h': 1, 'e': 1, 'o': 1})

# 从列表创建
counter2 = Counter([1, 2, 2, 3, 3, 3])
print(counter2)  # Counter({3: 3, 2: 2, 1: 1})

# 从字典创建
counter3 = Counter({'a': 3, 'b': 1})
print(counter3)  # Counter({'a': 3, 'b': 1})
```

#### 常用方法

```python
c = Counter("abcabc")
print(c)  # Counter({'a': 2, 'b': 2, 'c': 2})

# 获取最常见的元素
print(c.most_common())     # [('a', 2), ('b', 2), ('c', 2)]
print(c.most_common(2))    # [('a', 2), ('b', 2)]

# 获取所有元素（重复）
print(list(c.elements()))  # ['a', 'a', 'b', 'b', 'c', 'c']

# 总计数
print(sum(c.values()))     # 6

# 更新计数
c.update("aaa")
print(c)  # Counter({'a': 5, 'b': 2, 'c': 2})
```

#### 像字典一样使用

```python
c = Counter("hello")

# 访问计数
print(c['l'])    # 2
print(c['x'])    # 0 (不存在的键返回0，不会报错)

# 修改计数
c['l'] = 5
print(c)  # Counter({'l': 5, 'h': 1, 'e': 1, 'o': 1})

# 遍历
for char, count in c.items():
    print(f"{char}: {count}")
```

#### Counter 运算

```python
c1 = Counter("aab")
c2 = Counter("abc")

print(c1 + c2)  # Counter({'a': 3, 'b': 2, 'c': 1})
print(c1 - c2)  # Counter({'a': 1})  # 只保留正数
print(c1 & c2)  # Counter({'a': 1, 'b': 1})  # 交集
print(c1 | c2)  # Counter({'a': 2, 'b': 1, 'c': 1})  # 并集
```
