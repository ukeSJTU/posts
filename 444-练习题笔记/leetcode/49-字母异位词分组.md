## 题目描述 (Problem Description)

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

**示例 1:**

**输入:** strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

**输出:** [["bat"],["nat","tan"],["ate","eat","tea"]]

**解释：**

- 在 strs 中没有字符串可以通过重新排列来形成 `"bat"`。
- 字符串 `"nat"` 和 `"tan"` 是字母异位词，因为它们可以重新排列以形成彼此。
- 字符串 `"ate"` ，`"eat"` 和 `"tea"` 是字母异位词，因为它们可以重新排列以形成彼此。

**示例 2:**

**输入:** strs = [""]

**输出:** [[""]]

**示例 3:**

**输入:** strs = ["a"]

**输出:** [["a"]]

**提示：**

- `1 <= strs.length <= 104`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## 首次尝试思路 (My Initial Attempts)

### 第一次尝试 (Attempt 1)

- **我的思路:**
  - 计算输入的strs中每个字符串的哈希表
  - 维护一个字典mapping将同一个哈希表映射到一个列表，列表里面是哈希表相同的字符串
  - 将字典mapping转换成题目需要的`List[List[str]]`格式

```python
from collections import Counter
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        mapping = dict()
        for s in strs:
            mapping[Counter(s)] = mapping.get(Counter(s), []).append(s)
        print(mapping)
```

- **结果:** \* 错误 (Wrong Answer)

- **反思与失败原因:**
  - TypeError: unhashable type: 'Counter'

### 第二次尝试 (Attempt 2)

- **我的思路:**
  - 同一组异位词按照字母顺序排序后应该是一样的，比如说`["eat", "ate", "tea"]`等等，排序后都应该是`"aet"`，如果不是，说明不是异位词。

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        mapping = dict()
        for s in strs:
            key = "".join(sorted(s))
            if key not in mapping:
                mapping[key] = []
            mapping[key].append(s)

        return list(mapping.values())
```

- **结果:** 正确，11ms

- **反思与失败原因:**
  - 中间写错了一次：`mapping[key] = mapping.get(key, []).append(s)`这个报错：`AttributeError: 'NoneType' object has no attribute 'append'`。要注意append方法返回的是`None`

## 最优解法分析 (Analysis of Optimal Solution)

### 方法一：排序

这个和我的第二次尝试一样。

- **核心思路 (Sorting + Hash Table):**
  1. 创建一个哈希表（字典），用来存放 `排序后的字符串 -> 原字符串列表` 的映射。
  2. 遍历字符串数组，对于每个字符串 `st`，将其字符进行排序得到 `key`。
  3. **将排序后的字符串作为哈希表的键**。
  4. 把原字符串 `st` 添加到哈希表中对应键的列表里。
  5. 最后返回哈希表中所有的值（即分组后的结果）。

- **复杂度分析:**
  - 时间复杂度: $O(N \cdot K \log K)$
    - $N$ 是字符串数量，$K$ 是字符串的最大长度
    - 遍历 $N$ 个字符串，每个字符串排序需要 $O(K \log K)$
  - 空间复杂度: $O(N \cdot K)$
    - 哈希表需要存储所有字符串

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        mp = collections.defaultdict(list)

        for st in strs:
            key = "".join(sorted(st))
            mp[key].append(st)

        return list(mp.values())
```

### 方法二：计数

- **核心思路 (Character Counting + Hash Table):**
  1. 创建一个哈希表（字典），用来存放 `字符频次数组 -> 原字符串列表` 的映射。
  2. 遍历字符串数组，对于每个字符串 `st`，创建一个长度为 26 的计数数组。
  3. **统计字符串中每个字母（a-z）出现的次数**，记录在计数数组中。
  4. 将计数数组转换为元组（tuple）作为哈希表的键。
  5. 把原字符串 `st` 添加到哈希表中对应键的列表里。
  6. 最后返回哈希表中所有的值（即分组后的结果）。

- **为什么用元组（tuple）？**
  - Python 中列表（list）是可变类型，不能作为字典的键。
  - 元组（tuple）是不可变类型，可以进行哈希，因此可以作为字典的键。
  - 例如：`[3, 0, 0, 0, 1, ...]` 需要转换为 `(3, 0, 0, 0, 1, ...)`。

- **复杂度分析:**
  - 时间复杂度: $O(N \cdot (K + |\Sigma|))$
    - $N$ 是字符串数量，$K$ 是字符串的最大长度，$|\Sigma| = 26$
    - 遍历 $N$ 个字符串，每个字符串需要 $O(K)$ 统计字符，$O(|\Sigma|)$ 生成键
    - 由于 $|\Sigma|$ 是常数，实际可简化为 $O(N \cdot K)$
  - 空间复杂度: $O(N \cdot (K + |\Sigma|))$
    - 哈希表存储所有字符串，每个键需要 $O(|\Sigma|)$ 的空间
    - 实际可简化为 $O(N \cdot K)$

```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        mp = collections.defaultdict(list)

        for st in strs:
            counts = [0] * 26
            for ch in st:
                counts[ord(ch) - ord("a")] += 1
            # 需要将 list 转换成 tuple 才能进行哈希
            mp[tuple(counts)].append(st)

        return list(mp.values())
```

## 代码实现 (Implementation)

### C++

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (string& str: strs) {
            string key = str;
            sort(key.begin(), key.end());
            mp[key].emplace_back(str);
        }
        vector<vector<string>> ans;
        for (auto it = mp.begin(); it != mp.end(); ++it) {
            ans.emplace_back(it->second);
        }
        return ans;
    }
};
```

### `collections.defaultdict`用法

> `defaultdict`特点是：**当访问不存在的键时，会自动创建该键并赋予一个默认值**，而不是抛出 `KeyError`。

我的第二次尝试中有这样一段代码：

```python
if key not in mapping:
	mapping[key] = []
mapping[key].append(s)
```

为了处理key还不在mapping里面的情况，有点繁琐。可以改进：

```python
mp = collections.defaultdict(list)

for st in strs:
	key = "".join(sorted(st))
	mp[key].append(st)
```

| 类型     | 用法                          | 默认值  | 适用场景       |
| -------- | ----------------------------- | ------- | -------------- |
| `list`   | `defaultdict(list)`           | `[]`    | 分组、收集元素 |
| `int`    | `defaultdict(int)`            | `0`     | 计数           |
| `set`    | `defaultdict(set)`            | `set()` | 去重收集       |
| `str`    | `defaultdict(str)`            | `""`    | 字符串拼接     |
| `lambda` | `defaultdict(lambda: 默认值)` | 自定义  | 复杂默认值     |

我下面再举几个例子：

#### 1. **分组/归类问题** (最常用)

```python
# 按首字母分组
words = ["apple", "banana", "avocado", "berry"]
groups = collections.defaultdict(list)

for word in words:
    groups[word[0]].append(word)

# 结果: {'a': ['apple', 'avocado'], 'b': ['banana', 'berry']}
```

#### 2. 计数问题

```python
# 统计字符出现次数
text = "hello world"
counter = collections.defaultdict(int)  # 默认值为 0

for char in text:
    counter[char] += 1  # 第一次访问自动初始化为 0

# 结果: {'h': 1, 'e': 1, 'l': 3, 'o': 2, ...}
```

#### 3. 构建图/邻接表

```python
# 构建有向图
edges = [(1, 2), (1, 3), (2, 4), (3, 4)]
graph = collections.defaultdict(list)

for u, v in edges:
    graph[u].append(v)

# 结果: {1: [2, 3], 2: [4], 3: [4]}
```

#### 4. 嵌套字典

```python
# 二维分组
data = [("A", 1, 100), ("A", 2, 200), ("B", 1, 150)]
nested = collections.defaultdict(lambda: collections.defaultdict(int))

for category, subcategory, value in data:
    nested[category][subcategory] += value

# 结果: {'A': {1: 100, 2: 200}, 'B': {1: 150}}
```
