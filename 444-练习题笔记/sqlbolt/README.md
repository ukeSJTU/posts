# SQLbolt 学习指南

[SQLbolt](https://sqlbolt.com/) 是一个优秀的交互式 SQL 学习平台，通过精心设计的章节和实践练习，帮助用户系统掌握 SQL 基础知识和实用技能。该平台特别注重"边学边做"的学习方式，让初学者能够在实践中真正理解 SQL 的核心概念。

## 为什么选择 SQLbolt？

- **交互式学习体验**：每个概念后都有即时可执行的练习
- **循序渐进的课程设计**：从基础查询到复杂操作，难度适当递增
- **即时反馈机制**：练习后立即获得结果验证和解析
- **简洁清晰的界面**：专注于学习内容，减少干扰

## 本仓库内容

- **`notes` 文件夹**：包含 SQLbolt 各章节内容的中文翻译和详细解释
