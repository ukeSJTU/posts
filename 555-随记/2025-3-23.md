# PyTorch 如何管理显存？

今天在服务器上训练模型，发现已经被其他程序占用了所有的显存。这个时候如果我再运行另外一个消耗显存的程序肯定会报错，但是会不会影响到已经在运行的程序呢？我查了一下 PyTorch 的文档，发现 PyTorch 会自动管理显存。具体来说，PyTorch 会在每次分配显存时检查当前显存的使用情况，并根据需要释放不再使用的显存。

CUDA 运行时会为每个进程单独管理显存分配
显存不足只会影响请求分配的程序，不会导致已分配显存的程序崩溃
如果需要同时运行两个程序，可以考虑：
使用 torch.cuda.set_per_process_memory_fraction() 限制每个程序的显存使用
启用 PyTorch 的显存优化选项如 torch.cuda.empty_cache()
使用 CUDA 多进程服务 (MPS) 在支持的硬件上共享计算资源
这与 CPU 内存管理类似，一个程序的内存分配失败通常不会影响其他正在运行的程序。
