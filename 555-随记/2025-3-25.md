# 初学 go，发现原来可以不导入 fmt 包，直接使用 println 函数，代码如下：

```go
package main

func main() {
	if 7%2 == 0 {
		println("7 is even")
	} else {
		println("7 is odd")
	}
}
```

询问 AI：

是的，这个程序可以正常运行！你的代码是完全有效的 Go 程序，即使没有导入 `fmt` 包。

## 内置 println 函数

你注意到了一个重要的点。在 Go 中，有两类打印函数：

1. **内置函数** (`print`, `println`): 这些是语言内置的函数，不需要任何导入就可以使用。
2. **fmt 包函数** (`fmt.Print`, `fmt.Println`, `fmt.Printf` 等): 这些需要导入 `fmt` 包才能使用。

## 区别

内置的 `println` 和 `fmt.Println` 的主要区别：

### 内置 println:

- 不需要导入任何包
- 主要用于调试目的
- 输出格式较为简单
- 输出到标准错误 (stderr)
- 不返回任何值
- 不保证长期存在于语言中（虽然实际上一直都在）

### fmt.Println:

- 需要导入 `fmt` 包
- 设计用于正式的程序输出
- 提供更好的格式化控制
- 输出到标准输出 (stdout)
- 返回写入的字节数和可能的错误
- 是 Go 标准库的正式部分

## 示例比较

```go
// 使用内置 println
package main

func main() {
    println("Hello, World!")  // 不需要导入包
}
```

```go
// 使用 fmt.Println
package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")  // 需要导入 fmt 包
}
```

## 建议

对于正式的 Go 程序，特别是生产代码，推荐使用 `fmt` 包中的函数，因为：

1. 它们提供更丰富的功能（格式化、类型处理等）
2. 它们是标准库的正式部分，有更好的文档和支持
3. 它们的行为更可预测

内置的 `println` 主要用于快速调试，尤其是在你不想添加额外导入的情况下。

所以，你的程序完全正确，只是使用了内置的调试函数而不是标准库的输出函数。
