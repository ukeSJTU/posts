# Enhancing Large Language Models' Situated Faithfulness to External Contexts

增强大型语言模型对外部上下文的情境忠实性：论文总结

![arXiv-2410.14675.png](https://pub-cc2ebc8a43754210aa734d07c4898ad1.r2.dev/2025/03/arXiv-2410.14675.png)

## 研究背景与问题定义

大型语言模型(LLMs)常常通过外部信息作为上下文来增强其性能，但这些外部信息有时可能不准确甚至具有误导性。本研究提出了"情境忠实性"(situated faithfulness)概念，指 LLMs 应该能够根据内部知识和外部上下文的可信度动态调整其信任度。

研究表明，当提供正确和错误的上下文时，开源和专有模型都倾向于过度依赖外部信息，而不考虑其事实准确性。这使模型容易受到不可靠上下文的误导。

情境忠实性的目标是使模型能够在内部知识正确或外部信息不可靠时信任其内部知识，而在模型不确定或外部证据令人信服时依赖外部数据，从而最大化模型响应的准确性。

## 评估方法与数据集

研究者在多个问答数据集上评估了 LLMs 的情境忠实性能力，包括：

- FreshQA：包含不同时间敏感度和复杂度的问题
- NaturalQA：模拟真实世界搜索过程的开放域数据集
- TriviaQA：相对简单的开放域数据集
- PopQA：包含不同流行度的开放域问题

特别值得注意的是，研究者创建了一个新的数据集 RedditQA，其特点是包含来自 Reddit 帖子的真实世界错误上下文，这些错误会导致相应问题的错误答案。

为了全面评估，每个问题都配对了两种上下文进行测试：一个正确的上下文和一个错误的上下文，包括由语言模型生成和人类撰写的上下文。

## 提出的方法

研究者提出了两类增强 LLMs 情境忠实性的方法：

### 自导引置信推理 (Self-Guided Confidence Reasoning, SCR)

1. **隐式自导引置信推理(ImplicitSCR)**：模型被提示外部上下文可能不正确，必须依靠自己的判断来评估上下文的可靠性。为了鼓励使用内部知识，上下文在问题之后呈现。

2. **显式自导引置信推理(ExplicitSCR)**：模型首先基于内部知识和完全忠实于提供的上下文分别生成答案。然后，模型通过思维链过程进行明确的置信推理，评估内部答案和外部上下文的可靠性，最终选择最可信的答案。

3. **置信推理偏好优化(CR-DPO)**：通过优化模型对一对自采样推理路径的偏好来训练模型学习明确的置信推理。这种方法使模型能够通过直接偏好优化学习推理路径之间的偏好。[19]

### 规则基础置信推理 (Rule-Based Confidence Reasoning, RCR)

在这组方法中，为 LLMs 的内部和基于上下文的答案定义了不同类型的置信度估计，然后通过预定义的启发式规则进行推理：

1. **内部评估(InternalEval)**：LLM 自评估其内部答案的正确性。如果自评估表明答案正确，则选择内部答案；否则使用基于上下文的答案。[10]

2. **上下文评估(ContextEval)**：模型评估上下文相对于问题的正确性。如果上下文被认为是正确的，则使用基于上下文的答案；否则选择内部答案。[10]

3. **内部置信度阈值(InternalConf)**：LLM 评估其对内部答案的内部置信度。如果置信度超过预定义阈值，则选择内部答案；否则默认为基于上下文的答案。[10]

4. **上下文置信度阈值(ContextConf)**：LLM 评估外部上下文的可靠性。如果对上下文的置信度超过指定阈值，则选择基于上下文的答案；否则使用内部答案。[10]

5. **令牌概率校正(TPC)**：比较模型内部答案和上下文答案之间的置信度分数（平均令牌概率），选择得分较高的作为最终答案。[10]

## 实验结果与分析

### 主要发现

1. 对于具有强大推理能力的模型（如 GPT-4o 和 GPT-4o mini），SCR 方法优于 RCR 方法，在大多数数据集上始终达到最高的准确率，比直接输入增强有显著提升（GPT-4o mini 提高+17.8，GPT-4o 提高+24.2）。[13]

2. 对于较小的模型（如 Llama-3-8B），RCR 方法表现更好，特别是"InternalConf"方法。这表明 Llama-3-8B 虽然展示了一些内部置信度估计能力，但在有外部上下文时倾向于偏向它。[15][16]

3. CR-DPO 显著提升了 Llama-3-8B 的 SCR 性能，平均提高了 8.9%，并在不同上下文类型上表现出稳健性。[15][19][50]

4. RCR 方法受到规则设计、置信度提取中的噪声和偏差的限制，以及规则与置信信号之间的不一致性的影响。[17][18]

### SCR 的优势与改进

1. SCR 避免了 RCR 中规则设计、置信度提取的错误和偏差，通过在文本空间中直接执行置信度估计和推理，模型在这一领域运行更有效。[18]

2. CR-DPO 通过明确的思维链允许模型学习如何进行置信度评估，使其能够识别什么构成有效的置信推理。[19]

3. CR-DPO 允许模型通过强化学习探索各种推理路径，而不是过拟合到单一推理路径。[19]

4. 多任务训练增加了训练任务的多样性，通常可以改善域内和域外任务的置信推理。[19]

5. 在置信推理中，从模型自己的推理路径学习比使用来自更强模型的训练数据效果更好，因为置信推理依赖于将外部事实与模型的内部知识相互印证。[21]

## 结论与未来方向

本研究解决了使 LLMs 对外部上下文具有情境忠实性的挑战，在各种 QA 数据集上对其性能进行了基准测试。研究者提出了两类方法（SCR 和 RCR）来帮助 LLMs 调和外部知识与内部知识，以获得更准确的答案。[21]

研究发现，具有强大推理能力的模型（如 GPT-4o 和 GPT-4o mini）在 SCR 上表现优于 RCR，而较小的模型（如 LLaMA-3-8B）则 RCR 表现更好。研究者还观察到 RCR 受到置信度估计和规则设计中的噪声和偏差的阻碍。[21]

在 SCR 中，研究者提出了置信推理直接偏好优化（CR-DPO）来改进泛化能力。本研究提供了有价值的基准、稳健的实验和见解，为未来研究推进 LLMs 的情境忠实性铺平了道路。[21]

## Abstract

大型语言模型(LLMs)常常通过外部信息作为上下文来增强，但这些外部信息有时可能不准确甚至有意误导。我们认为，稳健的 LLMs 应当展现情境忠实性，根据它们对内部知识和外部上下文的信心动态调整对外部信息的信任度。为了对这一能力进行基准测试，我们在多个 QA 数据集上评估了 LLMs，包括一个新创建的名为 RedditQA 的数据集，其特点是包含来自 Reddit 帖子的真实错误上下文。我们发现，当同时提供正确和错误的上下文时，开源和专有模型都倾向于过度依赖外部信息，而不考虑其事实准确性。
为了增强情境忠实性，我们提出了两种方法：自导引置信推理(SCR)和规则基础置信推理(RCR)。SCR 使模型能够自我评估外部信息相对于自身内部知识的可信度，从而产生最准确的答案。相比之下，RCR 从 LLM 中提取明确的置信信号，并使用预定义规则确定最终答案。
我们的结果表明，对于具有强大推理能力的模型，如 GPT-4o 和 GPT-4o mini，SCR 优于 RCR，相比直接输入增强基线最高提升了 24.2%。相反，对于较小的模型如 Llama-3-8B，RCR 的表现优于 SCR。使用我们提出的置信推理直接偏好优化(CR-DPO)方法对 SCR 进行微调，可以提高在见过和未见过数据集上的性能，在 Llama-3-8B 上平均提升了 8.9%。
除了定量结果外，我们还提供了关于 SCR 和 RCR 相对优势的见解。我们的发现突显了改进 LLMs 情境忠实性的有前景途径。数据[^1]和代码[^2]已开放获取。

## Introduction

大型语言模型(LLMs)可以通过整合相关的外部上下文来增强其性能，这些上下文可由自动检索系统、工具、用户或其他模型提供(Chen 等，2017；Lewis 等，2020；Mialon 等，2023)。然而，外部信息常常不可靠，可能包含由网络错误信息、恶意的有意虚假信息(Zou 等，2024)、嘈杂的人类输入以及过时数据(Kasai 等，2023)导致的错误。先前的研究表明，LLMs 可能对外部上下文过度忠实，使它们容易受到不可靠上下文的误导(Petroni 等，2020；Xie 等，2023；Shi 等，2023；Shaier 等，2024)。

一个稳健的 LLM 不应盲目跟随外部信息，而应展现情境忠实性，动态平衡其对内部知识和外部上下文的依赖。这意味着当模型的内部知识正确或外部信息不可靠时，模型应信任其内部知识；相反，当模型不确定或外部证据令人信服时，则依赖外部数据。关键目标是最大化模型响应的准确性，无论外部上下文是否正确。为了实现这一点，模型需要强大的阅读理解能力来解释和提取准确信息，以及置信推理能力——自我反思模型对其内部知识的信心能力，并将其与外部上下文进行对比，以得出最准确的最终答案。

我们在多个问答任务上对当前 LLM 执行情境忠实推理的能力进行基准测试，包括 FreshQA（Vu 等，2023）、NaturalQA（Kwiatkowski 等，2019）、TriviaQA（Joshi 等，2017）和 PopQA（Mallen 等，2023）。这些数据集反映了跨领域的多样化世界知识。为了模拟内部知识优于外部证据或反之的场景，我们为每个问题配对了一个从网上检索的正确上下文和一个由 LLMs 合成的错误上下文。除了利用各种自动生成的上下文外，我们还通过 RedditQA 进一步研究 LLMs 如何处理人类撰写的错误上下文——这是我们创建的一个新数据集，通过从 Reddit 帖子中获取含有真实世界事实错误的错误上下文，这些错误会导致相应问题的错误答案。同期工作 ClashEval（Wu 等，2024）、FaithEval（Ming 等，2024）和 DynamicQA（Marjanović 等，2024）也对类似问题进行基准测试，但并不专注于解决方案。

我们确定了两类基于 LLM 的置信推理方法来改善情境忠实性（图 1）：自导引置信推理（SCR）和规则基础置信推理（RCR）。在 SCR 中，模型被告知外部信息可能不正确，并允许通过思维链隐式或显式推理得出最终结论。相比之下，RCR 首先提取模型关于内部知识和外部上下文的置信信号，然后应用预定义规则来选择信息源。

我们的实验表明：

1. 对于具有强大推理能力的模型，如 GPT-4o 和 GPT-4o-mini，SCR 优于 RCR，而对于较弱的模型如 Llama-3-8B，RCR 表现更好。
2. RCR 的性能受到置信提取和规则设计过程中引入的噪声和偏差的限制。
3. SCR 的有效性可以通过我们的新方法——置信推理直接偏好优化（CR-DPO）进一步增强，该方法使模型能够自行采样正确和错误的置信推理路径，并通过强化学习学会偏好最佳路径。CR-DPO 还提高了对未见数据的泛化能力，平均提升 Llama-3-8B 的性能 8.9%。

我们的研究为这一问题建立了基准，引入了稳健的方法和见解，使增强 LLMs 的情境忠实性成为一个有前景的研究方向。

## Related Work

具有输入增强的语言模型(Lewis 等，2020；Asai 等，2024)对许多应用场景很有价值，但容易受到嘈杂上下文的影响(Petroni 等，2020；Shi 等，2023)。过去的研究探索了定制语言模型以仅利用相关上下文(Li 等，2023a；Weston 和 Sukhbaatar，2023；Yoran 等，2024)。然而，这些方法没有考虑到那些相关但与 LLMs 参数化知识相矛盾的上下文。虽然 Pan 等(2023)触及了直接错误上下文的问题，但他们的重点仍然是 RAG 设置，缺乏对 LLM 内部行为的专门探索。

面对这种知识冲突(Xu 等，2024)，LLMs 表现出谜一般的行为。它们可能对外部证据过于接受(Xie 等，2024；Tan 等，2024)，同时又过度依赖参数化知识(Longpre 等，2021；Jin 等，2024)。Shi 等(2024)提出了一种融合解码器方法，在已知信息源可靠时信任上下文。Yu 等(2024)通过训练一个单独的分类器，使用分布内数据作为预处理步骤从上下文中删除不真实信息来解决知识冲突。然而，这依赖于分布内数据和模型的隐藏状态，限制了其实际应用。此外，在表面形式层面上这样做未能考虑各种语义粒度。与我们的工作同时进行的 ClashEval(Wu 等，2024)、FaithEval(Ming 等，2024)和 DynamicQA(Marjanović 等，2024)也对这个问题进行了基准测试，但没有专注于提供有效的解决方案。

已经证明 LLMs 能够估计其自身响应正确性的置信度(Kadavath 等，2022；Xiong 等，2023)。上下文知识冲突还要求模型将外部知识与内部知识相互印证，进行合理比较以得出最终结论。与我们的想法可能最相似的是同期工作 AstuteRAG(Wang 等，2024)，它提出通过考虑信息源可靠性来迭代整合内部和外部知识。他们的主要设置利用商业搜索引擎的实际结果，这在单一上下文中呈现了正确、错误和不相关证据的任意混合。为了对 LLMs 处理特定上下文的能力进行清晰评估，我们的设置在实例级别控制模型看到的证据类型。我们进一步探索了各种方法，包括基于置信度、基于自我评估和 DPO 方法，以引出模型解决知识冲突的能力——所有这些方法都表现有效。另一个同期工作 KnowPO(Zhang 等，2024)也采用 DPO 来教导模型如何解决知识冲突。然而，他们的方法仅基于最终答案使用偏好对，而我们的 CR-DPO 方法通过在最终答案之前纳入思维链(COT)推理来扩展这一点。这不仅增强了模型的推理能力，还提供了关于其最终决策的可解释性。

## Problem Set-up

### 3.1 Formulation

设 \[M\] 表示基于 LLM \[G\] 构建的 QA 模型（即 \[M\] 可以是独立的 LLM 或基于 LLM 的流水线）。给定一个 QA 实例 \[x = (q, c)\]，其中 \[q\] 表示问题，\[c\] 表示包含 \[q\] 答案的上下文[^3]，模型 \[M\] 生成答案 \[a = M(q, c)\]。

我们用函数 \[y(a) \in \{0, 1\}\] 定义模型答案 \[a\] 的正确性，其中 \[y(a) = 1\] 表示答案 \[a\] 是正确的（例如，与标准答案完全匹配），\[y(a) = 0\] 表示答案不正确。设 \[a*c\] 是上下文 \[c\] 所蕴含的答案，我们使用 \[y(c, q) \in \{0, 1\}\] 定义上下文 \[c\] 相对于问题 \[q\] 的正确性，其中当 \[y(a_c) = 1\] 时，\[y(c, q) = 1\]；当 \[y(a_c) = 0\] 时，\[y(c, q) = 0\]。类似地，设 \[a*{in}\] 是基础 LLM \[G\] 在没有任何上下文的情况下的内部答案，其中 \[a\_{in} = G(q)\]。

情境忠实性是指模型 \[M\] 无论外部上下文 \[c\] 是正确还是错误，都能提供正确答案的能力。因此，提高情境忠实性意味着最大化模型答案的准确性，无论上下文是否正确。具体来说，这涉及最大化以下概率：

- \[Pr(y(a) = 1 | y(c, q) = 1, y(a\_{in}) = 1)\]：当上下文和模型的内部答案都正确时，提供正确答案的概率。
- \[Pr(y(a) = 1 | y(c,q) = 1, y(a\_{in}) = 0)\]：当上下文是正确的，但模型的内部答案不正确时，提供正确答案的概率。
- \[Pr(y(a) = 1 | y(c,q) = 0, y(a\_{in}) = 1)\]：当上下文是不正确的，但模型的内部答案是正确时，提供正确答案的概率。
- \[Pr(y(a) = 1 | y(c,q) = 0, y(a\_{in}) = 0)\]：当上下文和内部答案都不正确时，提供正确答案的概率，这种情况不太可能得到改善。

参照 Yu 等人(2024)的研究，我们用以下指标量化情境忠实性：

- **给定真实上下文的准确率(Acc₁)**：模型在给定正确上下文时输出正确答案的概率：\[Pr(y(a) = 1 | y(c, q) = 1) \in [0, 1]\]
- **给定错误上下文的准确率(Acc₀)**：模型在上下文错误的情况下仍能输出正确答案的概率：\[Pr[y(a)= 1 | y(c, q) = 0) \in [0, Pr(y(a_{in}) = 1)]\]
- **整体情境忠实性**：\[SF = \frac{Acc*1+Acc_0}{2} \in [0, \frac{1+Pr(y(a*{in})=1)}{2}]\]

Acc₁ 的上限是 100%，因为理论上模型在所有上下文都正确的情况下可以达到完美准确率。相比之下，Acc₀ 受限于模型的内部准确率，因为错误的额外上下文不可能帮助模型解决它本身无法回答的问题。对于整体情境忠实性，其上限是 100%和模型内部准确率的平均值。

### 3.2 Datasets

为了全面基准测试情境忠实性问题，我们选择了跨越各个领域的多样化问答数据集。每个问题都经过两次测试，分别搭配正确和错误的上下文，这些上下文既包括由语言模型生成的，也包括由人类创建的。

#### 3.2.1 RedditQA

虽然许多问答数据集都附带着包含有价值支持证据的正确人类生成文档，但目前还没有专注于带有不准确信息的人类撰写文档的数据集，这引发了关于模型如何应对自然错误上下文的问题。为了填补这一空白，我们贡献了一个新的数据集，该数据集源自现有的 Reddit 帖子，这些帖子通常包含未经验证的、不准确的声明。具体而言，我们首先对 Reddit 帖子摘要应用声明检测器（(Völske 等人，2017)），过滤掉那些没有重要事实声明的帖子。然后，GPT-4o 评估这些声明是否可能包含不准确信息。对于被标记为不正确或不确定的声明，GPT-4o 生成一个自包含的多项选择世界知识问题，提供正确答案、错误答案以及两个合理的替代选项。接下来，我们使用自然语言推理模型检查不正确的帖子是否确实为问题提供了错误答案。

在自动化处理之后，我们进行人工评估以确保每个问题的有效性，通过验证以下标准：1）问题是否简洁、自包含，并且询问基于世界知识的可验证事实信息？2）答案是否得到了权威来源的确认，如权威网站（例如，政府网站、维基百科）或教科书？3）Reddit 帖子是否包含导致错误答案的不准确信息？4）其他合理的答案选项是否明显错误且可能具有误导性？5）来自在线来源的经验证证据是否正确地与问答实例的上下文配对？如果这些标准中的任何一个未满足，注释者会尝试纠正错误。对于无法纠正的数据点，注释者将丢弃它们。分步指导和其他注释细节可在§G 中找到。

#### 3.2.2 Other QAs

我们对当前大语言模型在多个问答任务中执行情境忠实推理的能力进行基准测试，这些任务涵盖了多样化的领域和不同难度级别。

- **NaturalQA**（Kwiatkowski 等人，2019）：一个开放域数据集，旨在通过专注于自然发生的问题来模拟真实世界的搜索过程。

- **TriviaQA**（Joshi 等人，2017）：另一个开放域数据集，由相对简单的问题组成，因为大多数大语言模型已经记忆了所需的知识。

- **PopQA**（Mallen 等人，2023）：包含不同流行度的开放域问题，包括模型可能没有记忆的低流行度问题。

- **FreshQA**（Vu 等人，2023）：包含具有不同时间敏感度和复杂性的问题，评估事实性和推理能力。为了与其他问答数据集保持一致，我们过滤掉了没有错误前提的数据。

- **ClashEval**（Wu 等人，2024）：一个当代数据集，包含来自多个领域的世界知识问题，每个问题都配有正确和经扰动的不正确上下文。这个数据集在撰写本论文时已经可用，我们将其作为评估的一部分。

对于 TriviaQA、NaturalQA 和 FreshQA，我们从相关网站检索正确的上下文，并使用自然语言推理模型进行验证。如有需要，GPT-4o 生成支持性上下文。错误上下文是通过让 GPT-4o 修改正确上下文以导向错误答案而创建的。对于 PopQA，我们使用 ConflictQA 上下文并进行预处理以过滤噪音。关于评估和数据集统计的更多细节在§A 中。

## 4 Methods

我们研究了两组提高大语言模型情境忠实性的方法。第一种是自导引置信推理(SCR)，即大语言模型意识到外部上下文可能不正确，并对其内部知识和提供的上下文进行置信度估计，通过推理得出最终答案。相比之下，第二种方法是基于规则的置信推理(RCR)，同样涉及对内部和外部知识进行置信度估计，但最终决策是根据预定义的外部规则而非模型自身推理来做出的。

### 4.1 Self-guided Confidence Reasoning

**隐式自导引置信推理（ImplicitSCR）** 模型被提示所提供的上下文可能不正确，并且必须依靠自己的判断来评估上下文的可靠性，然后提供最终答案。为了鼓励使用内部知识，上下文在问题之后呈现。我们的初步实验（§E）表明，这种排序结构使模型更倾向于依赖先验知识，从而减少对误导性上下文的敏感性。之后，模型在决策过程中隐式地推理置信度，并且只输出最终答案。（有关使用的实际提示，请参见§F.4）。

**显式自导引置信推理（ExplicitSCR）** 模型首先基于其内部知识（§F.1）和完全忠实于所提供的上下文（§F.3）分别生成答案。然后，模型使用思维链过程进行明确的置信推理。它首先评估对内部答案的置信度，反思它如何基于已知事实得出这个答案。接下来，它通过与支持其内部答案的事实交叉参考来评估外部上下文的可靠性。最终答案是通过推理两种视角，平衡内部和上下文置信度来选择的。（有关提示的详细信息，请参见§F.5。）

**置信推理偏好优化（CR-DPO）** 我们通过优化模型在一对自采样推理路径之间的偏好来训练模型学习明确的置信推理。首先，当模型的内部答案不正确时，我们提供正确的外部上下文，并要求它推理为什么上下文是正确的而其内部答案是错误的，从而产生一个被选择的推理路径。相反，我们对模型撒谎，告诉它上下文是不正确的而其内部答案是正确的，要求它相应地推理，生成一个被拒绝的推理路径。当模型的内部答案正确时，我们重复相同的过程，比较正确的内部推理与外部上下文。（有关这两个过程的提示，请参见§F.9）这种方法允许模型通过直接偏好优化（Rafailov 等人，2023）学习推理路径之间的偏好。此外，为了鼓励推理的多样性，我们使用双重采样：对于每个实例，我们使用不同的提示和上下文示例采样两对推理路径。遵循 Pang 等人（2024）的方法，我们将负对数似然应用于 DPO 损失，以改进推理过程的优化。（有关实施细节，请参见§B）

### 4.2 Rule-Based Confidence Reasoning

在这组方法中，我们为大语言模型的内部和基于上下文的答案定义了不同类型的置信度估计。置信度估计可以用数值分数或自我评估结果表示。然后通过预定义的启发式规则进行推理过程，这些规则通过比较这些置信度估计来确定最终答案。这里的所有方法都遵循相同的程序：1）分别生成内部答案和上下文答案（即使上下文错误也完全忠实于上下文）；2）估计每个答案的置信度；3）使用规则进行选择。

**内部评估（InternalEval）** 大语言模型使用§F.6 中的提示自我评估其内部答案的正确性。如果自我评估表明答案是正确的，则选择内部答案；否则，使用基于上下文的答案。

**上下文评估（ContextEval）** 模型评估相对于问题的上下文的正确性（提示见§F.7）。如果上下文被认为是正确的，则使用基于上下文的答案；否则，选择内部答案。

**内部置信度阈值（InternalConf）** 大语言模型评估其对内部答案的内部置信度。这里的推理规则是：如果这个置信度超过预定义的阈值，则选择内部答案；否则，模型默认使用基于上下文的答案。阈值可以预先定义为 0.5，或者如果可用，可以在同一数据集的开发分割的校准集上进一步调整。置信度分数可以是序列概率或其他置信度引出方法，如自一致性。

**上下文置信度阈值（ContextConf）** 大语言模型评估外部上下文的可靠性。如果对上下文的置信度超过指定阈值，则选择基于上下文的答案；否则，使用内部答案。阈值可以与内部置信度相同的方式确定。置信度分数可以通过给定上下文时答案的序列概率或自一致性来估计。

**（校准）令牌概率校正（TPC）**（Wu 等人，2024）比较模型内部答案和上下文答案之间的置信度分数（平均令牌概率），选择分数较高的作为最终答案——称为令牌概率校正。由于内部答案概率通常更加均匀，而基于上下文的概率往往是右偏的，这种方法可以通过比较置信度分数的百分位数而非原始值来进一步改进，从而得到校准的令牌概率校正。

### 4.3 Other Baselines

**直接输入增强** RAG 系统最简单且常见的实现是直接将问题与相应的上下文连接起来。我们遵循 Yu 等人（2024）描述的生成提示的相同结构，首先输入一个简单的指令，然后是与问题连接的外部上下文，形成一个提示，然后提供给模型。模型被指示在生成答案时利用外部上下文。我们使用 3 个示例（3-shot）来确保答案格式正确。（提示见§F.2）

**真实感知上下文选择** 与上下文评估类似，真实感知上下文选择（Yu 等人，2024）使用分类器在句子或令牌级别过滤掉上下文中不正确的部分。与在内部和基于上下文的答案之间进行选择的基于规则的方法不同，这种方法将过滤后的上下文重新输入大语言模型以生成最终答案。然而，它依赖于隐藏状态，这在 GPT-4 等专有模型中无法访问，并且需要领域内训练数据，使其与不需要这些的方法相比较不具可比性。因此，我们采用了一种替代方法：语言模型移除不真实的句子（TACS-LR）（提示见§F.8），并使用精炼后的上下文来产生最终答案。
