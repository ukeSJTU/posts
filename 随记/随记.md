今天做CS61A的lab00发现一个有趣的事情。`python -i xx.py`的运行的过程中修改源代码：

原本的`lab00.py`:

```python
def twenty_twenty_four():
    """Come up with the most creative expression that evaluates to 2024
    using only numbers and the +, *, and - operators.

    >>> twenty_twenty_four()
    2024
    """
    return ______

```

这个时候运行：`python3 -i lab00.py`，然后调用`twenty_twenty_four()`，报错如下：

```plaintext
python3 -i lab00.py
>>> twenty_twenty_four()
Traceback (most recent call last):
  File "<python-input-0>", line 1, in <module>
    twenty_twenty_four()
    ~~~~~~~~~~~~~~~~~~^^
  File "/Volumes/External/CS61A/lab00/lab00.py", line 8, in twenty_twenty_four
    return ______
           ^^^^^^
NameError: name '______' is not defined
```

然后不退出这个shell，修改源代码：

```python
def twenty_twenty_four():
    """Come up with the most creative expression that evaluates to 2024
    using only numbers and the +, *, and - operators.

    >>> twenty_twenty_four()
    2024
    """
    return 2024

```

再次调用`twenty_twenty_four()`，报错如下：

```python
twenty_twenty_four()
Traceback (most recent call last):
  File "<python-input-1>", line 1, in <module>
    twenty_twenty_four()
    ~~~~~~~~~~~~~~~~~~^^
  File "/Volumes/External/CS61A/lab00/lab00.py", line 8, in twenty_twenty_four
    return 2024
           ^^^^
NameError: name '______' is not defined
```

会发现这个traceback是不完全匹配的。
